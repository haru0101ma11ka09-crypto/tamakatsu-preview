# タマ活（就活診断）LP 共同編集用リポジトリ

公開ページ：https://haru0101ma11ka09-crypto.github.io/tamakatsu-preview/

> このページは、実際にみんなが診断する本番ページとして使っています（tamakatsu.pages.dev は現在使っていません）。
> 電話番号フォームは、同意にチェックして「次へ」を押すと、架電管理用のGoogleスプレッドシートに送信されます。送信先は`site-config.js`の`webhookUrl`で設定し、空のあいだは何も送信しません。公式LINE・予約はまだ未接続、先輩の写真とプロフィールは仮サンプルです。
> 同意文言（電話をかける目的の説明）はまだ「仮」です（先輩が正式な文言を作成中）。正式な文言が決まったら、`index.html`の文言と`CONSENT_VERSION`を更新してください。

## 2人での編集の流れ（かんたん版）

GitHub のページ上だけで編集できます。ソフトのインストールは不要です。

1. このリポジトリで、直したいファイルを開く（下の「どのファイルを直す？」を参照）
2. 右上の鉛筆マーク（Edit）を押して、文章を直す
3. 右上の緑のボタン「Commit changes…」を押す
4. 一言メモ（例：トップの見出しを変更）を書いて「Commit changes」
5. 1〜2分待つと、公開ページに反映される（スマホで開き直して確認）

### 2人が同時に直すときのコツ
- 同じファイルを同時に編集しない（先に「今から○○を直す」と声をかける）
- 大きく変えるときは、「Commit changes」の画面で **「新しいブランチを作る」** を選び、「Pull request」を作る。相手が確認して「Merge」を押すと反映される
- 間違えても、履歴（History）から前の状態に戻せる

## どのファイルを直す？

| 直したいこと | ファイル |
|---|---|
| 見た目（色・文字サイズ・余白・ボタン） | `tama-v2.css` |
| 画面の構成・文言（トップ、タブ、面談ページなど） | `index.html`（中の `<script>` 内にHTMLがあります） |
| 45問の設問、16タイプの結果文章 | `diagnosis-data.js`（**採点・文言は勝手に変えない。相談してから**） |
| 結果の詳細レポートの文章 | `result-guidance.js`（同上） |
| 公式LINEのURL、架電管理シートへの送信先URL（決まったら入れる） | `site-config.js` |
| 画像・動画 | `assets/` フォルダ |
| 結果画面の確認用ページ | `result-preview.html?type=ACTP`（`ACTP` を他のタイプに変えて確認） |

## 変えないもの（約束）
- 45問の設問と選択肢、採点ロジック、逆転採点、4軸の割合、50％時の判定
- 16タイプの対応と診断結果の文章
- PC用・スマホ用の孵化動画と自動遷移
- 下部4タブ（診断／就活タイプ／就活面談／公式LINE）。メンター紹介は就活面談の「メンターのプロフィールを見る」から開く
- 全ページの「Produced by BEYOND CAFE」と公式ロゴ
- キャラクター画像は描き直さない・切り取らない
