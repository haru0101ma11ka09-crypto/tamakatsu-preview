# メンター管理画面の公開デモ

GitHub Pages上の `admin-demo/` で画面と操作を試せます。

- 実際のGoogle認証、APIサーバー、メール送信はありません。
- 編集内容は操作中のブラウザーのlocalStorageだけに保存されます。
- 端末間・利用者間のデータ共有や、本番サイトへの反映はありません。
- 実在するメールアドレス、個人情報、機密情報は入力しないでください。
- 「管理者として画面を確認」「メンターとして画面を確認」は表示範囲を試すためのデモです。アクセス制限として使用しないでください。
- データを戻すにはログイン後の「デモを初期化」を押してください。

`demo-api.js` は別途作成したPythonアプリと同じ `/api/mentors`・`/api/reviews`・`/api/accounts` の契約で、ブラウザー内のデモデータを操作します。将来のAPI接続時はデモ用トランスポートを外し、Googleログイン、サーバー側の権限検証、永続保存を備える実サーバーへ切り替えます。クライアント側のデモ権限を本番認証として流用しないでください。

既存の診断サイト・プロフィールデータ・レビュー送信先は変更していません。

## メンター追加・本人限定編集

管理者は一覧の「メンターを追加」で、表示名と本人のGoogleメールアドレスを登録します。プロフィール詳細の「編集アカウントの紐づけ」から変更もできます。全員がすべてのプロフィールを閲覧でき、本文・写真を編集できるのは紐づいた本人だけという操作を再現しています。管理者も保持者でないプロフィール本文は閲覧のみです。

ログアウト後の「登録したデモアカウントで確認」から、追加した本人の表示を試せます。これは実際のGoogle認証ではありません。実際の本人限定アクセス制御は、別途用意したサーバーAPIの接続後に有効になります。架空のメールアドレスを使ってください。

## 担当学生の管理

各メンターのプロフィール詳細から「担当学生・進捗を見る」を開くか、管理メニューの「担当学生の管理」を使用します。運営管理者は全担当の学生、メンターは自分の担当学生だけを確認できます。ほかのプロフィールの閲覧権限があっても、学生情報は閲覧できません。

氏名・メール・電話（任意）・大学・卒業年・診断タイプ・メンター選択日・進捗・次の対応日・対応メモを保存できます。進捗は未対応／連絡済み／面談予定／面談済み／支援中／内定・完了／終了です。更新履歴には保存した時点の進捗・メモ・日時・操作アカウントが残ります。検索と担当・進捗での絞り込みも可能です。

**公開デモには実在する学生の個人情報を入力しないでください。** サンプル学生は架空のデータです。デモのロール切り替えは本物のアクセス制限ではありません。実データの本人確認とアクセス制限はサーバーAPI接続後に有効になります。

現在の公開サイトでメンターを選択しても、この管理画面には自動登録されません。学生の選択・同意・本人確認と連携する受付APIは今後の接続作業です。現時点は「学生を登録」から手動で試せます。学生の情報やメモはGitHub Pagesのファイルや一般公開APIへ出力しません。

このデモは確認のため、ユーザーの承認を得て mentor-admin/ に一時公開しています。Google認証はなく、URLを知っている人は誰でも開けます。架空データのみ入力してください。データ共有・学生の自動取り込みはありません。

## 出身学校・面談プラン（追加）

プロフィール編集に「出身学校」と「面談プラン」（最大3つ。タイトル・内容・時間）を追加しました。公開サイトのメンター一覧のカード（業種・職種・出身学校の3つのタグと、面談プラン）と、プロフィール詳細に表示される項目です。別途用意したサーバーAPI（`/api/mentors`）にも、`university`（文字列）と `plans`（`title` `text` `duration` `place` `image`）を足す必要があります。公開サイトへの自動反映はまだありません（`mentors-data.js` が元データです）。
